# Reality Thrive

A responsive, founder-led marketing website for Emmanuel Atunramu and Reality Thrive. The positioning emphasizes website design, connected business systems, practical workflow automation and ongoing digital support rather than AI as the whole brand.

## Sections
- Founder-led hero and portrait
- Website design, CRM and lead systems, workflow automation, AI voice agents, online business support
- Reality Thrive Digital Care ongoing partnership
- Process, founder bio and social profiles
- Email-based enquiry form (does not store submissions)

## Brand palette
- Near-black: #100D0A
- Golden yellow: #FFC400
- Warm orange: #EF762A
- Warm paper: #F5F1E9

## Local preview
Open index.html in a browser or run a static server from this directory.

## Deploy to Vercel
Import this repository and use Framework Preset **Other**. Leave the build command blank and use the repository root as the output directory. No environment variables or build step are required.
