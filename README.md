# Reality Thrive AI

Responsive marketing website for Reality Thrive AI, founded by Emmanuel Atunramu.

## Included
- Website design and development positioning
- AI voice agents, CRM and workflow automation services
- Reality Thrive Digital Care ongoing-support offer
- Founder introduction and email contact CTA
- Responsive navigation and mobile layouts
- Static deployment configuration for Vercel

## Brand palette
- Near black: #090807
- Warm yellow: #FFC400
- Orange: #F26B21
- Warm paper: #F3F0E8

## Deploy to Vercel
Import this repository into Vercel. Framework preset: Other. Build command: leave blank. Output directory: . No environment variables are required for this static site.
